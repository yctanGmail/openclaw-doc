
## 📂 各目录说明

### 📝 scripts/ - Python 脚本

**存放所有自动化脚本**

| 文件 | 说明 |
|------|------|
| `evening_review_enhanced.py` | **盘后复盘脚本** - 获取实时大盘和个股数据，生成复盘报告 |
| `morning_brief_v2.py` | **盘前简报脚本** - 生成盘前市场分析和策略建议 |
| `github_sync_enhanced.py` | **GitHub 同步脚本** - 自动将报告推送到 GitHub 仓库 |
| `stock_price_alert.py` | **价格预警脚本** - 监控股价，触发阈值时推送飞书通知 |
| `stock_price_monitor.py` | **股价监控脚本** - 定时获取股票实时数据 |
| `parse_market_data.py` | **数据解析脚本** - 解析腾讯财经 API 返回的市场数据 |
| `get_valuation.py` | **估值分析脚本** - 获取股票 PE/PB 等估值数据 |
| `price_alert.py` | **价格提醒脚本** - 设置和管理价格预警 |

## 🤖 Agent 角色

| Agent | 名称 | 职责 |
|-------|------|------|
| `lead` | **小甜心** | 总协调人，谭老师的 AI 合伙人，负责审核和推送 |
| `market` | **小探** | 市场研究分析师，负责获取数据和分析市场 |
| `dev` | **小码** | Python 开发工程师，负责编写和维护脚本 |

## 📈 工作流程

```
1. 盘前（09:00）
   小探获取数据 → 生成盘前简报 → 小甜心审核 → 推送给谭老师

2. 盘中（09:30-15:00）
   价格预警系统每 15 分钟监控 → 触发阈值时推送

3. 盘后（15:30）
   小探获取收盘数据 → 生成复盘报告 → 小甜心审核 → 推送给谭老师

4. 同步（每 2 小时）
   GitHub 同步脚本自动将报告推送到仓库
```
